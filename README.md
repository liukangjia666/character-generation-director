# Character Generation Director

跨图片与视频保持角色身份一致的角色生成导演技能。

这个技能把角色从一句概念，整理成可以反复生成、可以换装、可以换景、可以表演，并且在不同镜头里仍然保持身份稳定的角色资产。它适用于角色母版、角色卡、静态人物图、多视图设定、短剧角色锁定、电影级人物表演、动漫/三维角色、武打动作和技能释放提示词。

## 解决的问题

普通角色提示词经常只写“漂亮、帅气、古风、电影感”，但没有说明这些词如何落到脸、轮廓、服装、动作和镜头上，生成后容易出现：

- 同一角色换镜头后换脸、换发型或换服装结构
- 日常装、战斗装和变身形态之间没有身份继承
- 多角色脸型、轮廓和色彩语言过于相似
- 角色有设定，却无法完成自然对白、打斗或技能动作
- 真人摄影、二维动漫、三维游戏和概念艺术的媒介语言混在一起
- 道具突然复制、换手、消失，或与角色身体穿插
- 技能特效遮住脸和动作，最后只剩一团光

技能的核心方法是区分三层角色状态：

1. **身份母版**：脸部结构、年龄感、发型轮廓、体型和身份标记。
2. **外观版本**：日常装、礼服、战斗装、战损装、着甲或觉醒形态。
3. **镜头状态**：这一刻的站位、朝向、视线、持物、接触、表情和动作。

## 适用场景

### 红果式竖屏短剧

适合9:16短剧角色出场、多人对话、误会、暧昧互动和快速反转。重点控制：

- 首屏能否快速认出人物和关系
- 面部、关键道具和手部动作是否位于手机画面的可读区域
- 台词、嘴型和声音归属是否明确
- 多人站位和视线是否连续
- 服装色块与身份标签是否清楚

### 真人电影与高规格剧集

适合古装、现代、武侠、仙侠、科幻和现实题材。重点控制：

- 真实皮肤、头发、布料、金属和建筑质感
- 光源方向、阴影软硬、景深和色彩关系
- 克制的微表演、停顿、视线和呼吸
- 角色服装与动作的物理可行性
- 人物和环境的空间关系

### 二维动漫与漫画

重点控制角色的轮廓、头身比例、发型分束、线条、色板、阴影边界和表情稳定性。二维角色不使用真人毛孔、摄影景深或PBR渲染作为核心描述。

### 三维动画与游戏角色

重点控制轮廓、材质分区、关节活动、装甲连接、武器挂点、装备版本和技能状态。写实3D、风格化3D和游戏立绘需要分别组织，不能只更换一个“3D”标签。

### 对白、武打与技能释放

技能会把角色身份和镜头行为连接起来，控制：

```text
起始状态 → 可见动作路径 → 接触或释放 → 受力与环境反馈 → 结束状态
```

适用于画内对白、画外声音、表情节拍、武器动作、近身打斗、法术释放、机甲变身、异兽技能和多形态角色。

## 工作方式

技能会先判断三个维度：

```text
交付类型：角色卡 / 静态图 / 多视图 / 视频角色锁定 / 表演 / 技能
媒介：真人 / 2D动漫 / 风格化3D / 写实3D / 非人或机械
用途：短剧 / 电影 / 动画 / 游戏 / 广告 / 社交视频
```

然后按照以下顺序处理：

1. 理解角色的故事功能和观众需要首先认出的信息。
2. 建立不可变身份锚点。
3. 区分外观版本和镜头状态。
4. 按媒介设计脸、轮廓、服装、材质、道具和动作。
5. 将参考图、首帧、音频和角色卡分别绑定到具体用途。
6. 根据目标交付写静态图、视频表演或技能提示词。
7. 检查身份连续性、空间关系、动作可见性和媒介冲突。

## 推荐使用方式

### 角色母版

```text
用 character-generation-director 设计一名古装真人电影女主。
她是冷静的女捕快，成年，身穿深青色窄袖官服。
请输出角色母版、身份锚点、动作签名和禁改项。
```

### 红果短剧角色

```text
用 character-generation-director 设计一组三人红果短剧角色。
画幅9:16，真人写实，现代室内，重点是20秒误会对话。
请输出三张角色卡、人物区分点和角色视频锁定规则。
```

### 电影级角色

```text
用 character-generation-director 设计一名东方古装电影男主。
请区分身份母版、日常服、战斗服，并给出电影级角色剧照提示词。
```

### 动漫或三维角色

```text
用 character-generation-director 设计一名写实3D机甲角色。
请输出轮廓锚点、装甲结构、武器挂点、变身前后继承关系和技能释放提示词。
```

### 参考资产绑定

```text
角色脸部使用 #{imageId:1234}#，服装使用 #{imageId:5678}#，声音使用 #{audioId:9012}#。
请说明每份参考分别锁定什么，并生成一段15秒角色表演提示词。
```

## 输出类型

根据用户需求选择一种或几种：

- 角色母版卡
- 单张真人或动漫角色提示词
- 正面、侧面、背面三视图提示词
- 表情设定与动作签名
- 日常、礼服、战斗、战损和觉醒变体
- 红果式竖屏短剧角色锁定提示词
- 电影级角色表演提示词
- 对白、画外音和多人互动提示词
- 武打、法术、异能和机甲技能提示词
- 已有提示词的结构诊断与优化

用户只需要一种交付时，不默认输出完整资产包。

## 关键提示词结构

### 角色母版

```text
【角色代号/姓名】
【故事功能与关系】
【媒介与题材】
【年龄感、体型与身高关系】
【脸部身份锚点】
【发型与头饰锚点】
【轮廓与动作签名】
【服装层次与材质】
【道具与技能】
【声音与表演】
【允许变化】
【禁止漂移】
【参考资产映射】
```

### 视频角色表演

```text
【角色与当前外观版本】
【可见空间锚点】
【镜头起始状态】
【动作或表演节拍】
【对白与声音归属】
【摄影机可见范围】
【结束状态】
【关键身份连续性约束】
```

### 技能释放

```text
【技能来源】身体、武器、法器或环境
【触发方式】手势、蓄力、姿态或接触
【视觉形态】形状、颜色、体积和内部结构
【运动路径】从哪里到哪里，如何加速和转向
【作用对象】命中位置与具体效果
【环境反馈】雨雾、水面、衣发、墙体、地面和光线
【角色可见性】哪些阶段仍能看见脸、身体、武器和动作方向
【消散与终态】技能如何消失，角色和场景留下什么变化
```

## 参考图使用原则

每份参考图必须有明确职责：

| 参考类型 | 可以锁定的内容 |
|---|---|
| 面容图 | 脸型、五官结构、皮肤年龄感、身份标记 |
| 发型图 | 发际、分缝、发束、后脑轮廓、头饰位置 |
| 服装图 | 服装版本、层次、纹样、材质与穿法 |
| 体型图 | 身高关系、肩腰比例、体态和动作范围 |
| 首帧图 | 当前镜头的站位、姿态、道具和光线 |
| 场景图 | 空间结构、地标、背景材质和光源 |
| 音频参考 | 声线、语速、口音和情绪基线，前提是音频可访问 |

技能不会因为存在图片句柄，就假装已经看到了图片内容。没有可见内容时只使用用户明确提供的文字信息。

## 生成前检查

输出前检查：

1. 主媒介是否明确，真人、二维、三维和概念艺术是否混用。
2. 角色脸、发型、体型、服装、道具和声音是否有正确的参考映射。
3. 身份母版、外观版本和镜头状态是否被区分。
4. 同一角色在不同视角、表情、服装和技能状态下是否仍有辨识锚点。
5. 多人是否有足够的脸型、轮廓、服装或动作差异。
6. 画幅、构图和动作是否让脸、手、武器与关键道具保持可见。
7. 对白是否由正确角色说出，其他角色是否只做倾听反应。
8. 武打是否有起势、攻击路径、接触点、受力反馈和收势。
9. 技能是否有来源、轨迹、作用、环境反馈和消散状态。
10. 负向提示词是否只针对当前媒介与真正高风险的问题。

## 边界与限制

这个技能负责角色设计、角色资产绑定和角色相关提示词。它不会保证任意视频模型绝对不换脸、不错位或不改变服装；实际生成失败时，需要根据具体失败镜头修订身份锚点或动作状态。

它不替代完整的视频分镜技能。涉及完整场景的时间轴、摄影机调度和多镜头剪辑时，建议配合通用视频提示词技能使用。
