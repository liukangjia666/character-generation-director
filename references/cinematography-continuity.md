# 镜头、空间与状态连续

镜头先服务观众需要看清的事实，再选择术语。每个镜头至少回答：摄影机从哪里开始，跟谁的哪个动作，运动到哪里，观众最终看清什么，镜头结束时留下什么状态。

## 镜头句式

```text
景别 + 机位起点 + 运镜方式 + 跟焦主体 + 运动方向与速度 + 可见信息 + 停止位置
```

示例：

```text
侧面中景，摄影机位于两人的运动轴线外侧，跟焦持剑者的剑尖；镜头与人物同速横向移动，完整保留刺击、拨剑、回收和换脚；剑尖回到防守线后，镜头停住并让两人重新同框。
```

## 运镜选择

- 贴背跟拍：保留主体与前方目标的关系，适合追击和压迫。
- 侧向跟拍：展示距离变化、攻击路径和换位。
- 前导跟拍：表现人物迎面接近和表情变化。
- 推镜：让观众更接近一个信息或情绪，说明推进对象。
- 拉镜：揭示空间规模、结果和人物与环境的关系。
- 甩镜：只用于明确的突然变向或动作转场，甩完必须有稳定落点。
- 环绕：用于展示主体转身或关系变化，写明起止侧，避免无意交换左右。
- 俯拍：用于确认多人位置、地面轨迹、障碍和换位。

## 空间锚点

不要只写“左边、右边”。同时写门、柱、桌、桥、台阶、窗、祭坛等固定地标，并记录：人物相对地标的位置、朝向、距离、前后层级、手持物和运动轴线。换机位后重新说明当前画面关系。

## 状态继承表

复杂片段每镜结束后在内部维护：

```text
角色位置与高度：
身体朝向：
视线目标：
手和脚的状态：
武器或道具所在手及角度：
与他人的距离或接触：
服装、伤势和战损：
情绪或战局优势：
下一镜起手动作：
```

下一镜必须从这组状态开始。转身、换手、换位、变装、道具出现或消失必须拍出过程。首帧和尾帧任务中，明确哪些元素在首帧不存在、何时进入、何时离开，以及尾帧如何恢复。

## 切镜与转场

切镜依附真实动作节点：遮挡、擦身、挥臂、物体掠过镜头、急停、视线转向、接触、落地或能量坍缩。转场要写触发动作、遮挡物、下一镜的匹配形状和恢复后的状态。不要只写“丝滑转场”。

## 时间可行性

每段时间只安排一个主要动作任务。复杂动作要留出接近、接触、受力、收势和结果的时间。若一个时段同时要求变装、转身、技能爆发、换位和特写，删减动作或拆成多段；不要用更多形容词掩盖时间不足。
