# 角色身份与资产系统

当任务涉及多图、多镜、换装、角色卡、真人演员参考或系列角色时使用。目标是让“同一个角色”成为可验证的制作约束，而不是反复写“保持一致”。

## 参考图的职责分离

把输入逐个登记为：`引用句柄 | 内容能否查看 | 用途 | 锁定强度 | 与其他参考的关系`。

常见用途：

- 面容：脸型比例、五官位置、皮肤年龄感、不可变标记。
- 发型：长度、分缝、前额、鬓角、后脑轮廓、饰物。
- 服装：具体版本、层次、配色、纹样、穿着方式。
- 身体：身高差、体态、肩腰比例、习惯姿势。
- 首帧：当前镜头的站位、朝向、姿态、道具、光线。
- 声音：音色、口音、语速、年龄感、情绪基线；只有音频真实可访问时才分析听感。
- 场景：不可代替人物资产；不要从场景图推定未出现的服装或道具。

看不到引用内容时保持句柄，使用用户已经说明的事实。不要写“参考图中的眼睛是……”之类未经核验的结论。参考只提供部分身体或服装时，不推断未拍到的背面结构；为生成所需作设计时，将其标为补充设计。

## 角色母版字段

不是每次都全文输出；创建资产包或长期角色时使用完整卡。

```text
角色代号与称呼：
故事功能与关系：
媒介、题材、年代或世界规则：
年龄感、体型和身高关系：
脸部固定点：轮廓比例、眉眼、鼻唇、皮肤特征、标记；只选能分辨身份的重点。
发型固定点：前额、侧面、后脑的形状及标志性饰物。
轮廓与动作习惯：站姿、步态、重心、手势。
基础服装：层次、剪裁、材质、颜色、鞋履、可运动性。
配件与道具：数量、形态、持有位置和使用方式。
声音与表演：声线、语速、呼吸、面部与身体表达（需要视频时）。
允许变化：哪些外观和状态可因剧情变化。
禁止漂移：哪些部位、比例、身份与标记绝不可变化。
参考资产与用途：各 imageId/audioId/首帧等对应什么。
```

角色背景只保留能改变外观、表演或行动选择的部分。不要用大段传记替代画面信息。历史或民族服饰有明确依据时尊重参考；不确定时写风格来源，不伪称严格考据。

## 不可变、版本和瞬时状态

将同一角色拆成三张卡，防止连续性混乱：

| 层级 | 示例 | 何时可变化 |
|---|---|---|
| 身份母版 | 面部结构、年龄感、关键印记、声线 | 仅用户要求重设计或明确剧情变身 |
| 外观版本 | 朝服、常服、战损、着甲、湿发 | 指定时间点或场景变化时 |
| 镜头状态 | 右手持剑、左臂受伤、背对门、正在说话 | 随镜头动作推进，但需有可见转移 |

变身、着甲、异化、年龄跨度等必须规定：哪些身份标记在各阶段可辨，变化如何开始与完成，脱离状态后如何恢复。完整换装不能在连续镜头中凭空发生，除非世界规则明确允许且变化过程被拍到。

## 多人角色区别

每个主要角色至少有两种稳定区别：脸部结构、发型轮廓、身高体态、服装色块、佩物、动作习惯或声线。避免所有人都用“精致脸、长发、白衣”；不要通过肤色或刻板外貌代替性格。

多人图或视频首先列出身份绑定与关系：谁与谁并肩、对视、接触、说话、持物。镜头反打要按新机位重新表述屏幕左右，不改人物实际相对位置。一个角色说话时，其他人只做倾听反应，不同步张嘴。

## 变体矩阵

系列图或多版本时明确每次只改变哪些轴：

```text
保持：脸部母版、发型核心轮廓、体型、身份印记。
变化轴：服装 / 年代 / 场景 / 表情 / 光线 / 战损 / 技能阶段。
版本A：日常态。
版本B：战斗态；只变服装、防具和姿态。
版本C：技能释放态；增加可溯源能量，不遮挡面容与轮廓。
```

如果用户提供的图像彼此冲突，优先遵循其指定的“脸以图1、衣服以图2、姿态以图3”等用途。没有指定时先依据最明确的角色卡；若冲突会改变身份，简要说明假设或询问，不擅自混合两张不同的脸。

## 同一角色的可见连续性测试

- 正面、四分之三侧脸、侧脸、背影是否仍有一致的发型与体态。
- 远景是否能通过轮廓、色块或道具认出人；近景是否保住脸和皮肤/线条细节。
- 服装换版后是否至少保留足够的面容、发型或标记锚点。
- 角色在上一镜持有或佩戴的道具，下一镜是否有明确的收起、交付、掉落或继续持有。
- 变身后的身份是否有可见继承，而不是出现一套毫无关联的新角色。
