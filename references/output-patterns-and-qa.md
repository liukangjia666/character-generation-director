# 输出母版与质量检查

这些是可取用的模块，不是每次都要全部输出。完整资产包可包含角色卡、形象提示词、版本矩阵、表演或技能提示词；单次请求只交付用户真正需要的部分。提示词写作采用用户语言，保留其参考句柄、角色名、时间码和明确禁项。

## A. 角色母版卡

```text
【角色代号/姓名】
【用途】主角/对手/配角；短剧/电影/动画/游戏等。
【核心身份】年龄感、背景、故事功能与关系。
【视觉锚点】脸、发型、体型、关键标记、主色与轮廓。
【造型版本】日常/礼服/战斗/受伤等；逐版说明继承项与变化项。
【表演签名】眼神、呼吸、手势、步态、声音（需要时）。
【道具与技能】数量、位置、持用方式、来源与作用。
【参考映射】图片、音频、首帧各负责什么。
【禁改项】不能漂移的身份与结构。
```

避免一开始就写“性格孤傲、命运复杂”而不给可见动作。每个抽象词至少有一个能拍到或画出的对应细节。

## B. 单张真人角色图

```text
【媒介与用途】真人摄影 / 古装电影剧照 / 角色试妆照；画幅与景别。
【身份锁定】引用图负责面容、发型、服装的范围；同一人。
【可见外观】脸部结构、皮肤年龄感、发型、服饰层次和材料。
【身体与道具】姿态、手势、持物位置与接触关系。
【场景与摄影】背景层次、机位、光源、色彩及焦点；主体无遮挡。
【负面约束】该图最可能出现的换脸、服装误差、塑料材质、手部错误等。
```

电影剧照可保留剧情痕迹；角色标准照优先看清面部、全身结构和服装，不用烟雾与极浅景深遮掉资产。

## C. 多视图/表情/变体图

```text
【版式】正面、左侧、背面、四分之三侧面或指定顺序；同一角色同一比例。
【共同条件】统一脸部骨相、发型根部、服装层级、鞋履、道具与光照。
【逐视图可见结构】发饰背面、领口闭合、肩部连接、衣摆、武器挂点。
【表情/动作差异】仅改变指定表情或姿态，面容不换人。
【变体差分】保留身份锚点，列出每一版真正改变的元素。
```

风格化角色使用统一线条和色板；真人多视图用中性可比的光与镜头高度。不要让正侧背分别成为不同造型。

## D. 竖屏短剧角色出场或对话

```text
【总时长与画幅】用户指定的上限内；通常按9:16设计，除非用户另定。
【角色卡与当前版本】谁出镜、穿哪一套、谁只画外发声。
【可见空间锚点】门、桌、窗等固定背景；人物相对位置与机位。
【镜头01｜时间｜任务】起始状态；人物先看/听见什么；微表情或动作路径；台词与嘴型；其他人反应；结束状态。
【镜头02……】承接上一镜的站位、服装、道具与情绪。
【关键禁止】角色换脸、口型串人、凭空新增人物、道具跳手等。
```

首屏突出角色或关系钩子，但不强迫每秒都有反转。多人对话先保证说话人与反应者清楚，别让每个人始终盯着镜头。

## E. 电影级角色表演片段

```text
【角色与关系】人物在这场戏的目标、克制与对方的存在。
【场景与真实光源】时间、空间、材质、服装使用状态。
【镜头任务】观众先知道什么、何时发现变化、最终停在什么反应。
【表演节拍】视线、呼吸、肌肉、手势、重心、台词或沉默。
【摄影机】景别、机位、焦点与运动的具体动机；保留必要空间。
【声音】环境、衣料、脚步、台词归属和停顿。
【终态】角色关系、姿势、道具和下一镜接点。
```

长镜头可少切但要有内部变化；精细表演不等于每句都写满微表情。留一个观众能够主动发现的细节。

## F. 动漫/三维角色动作或技能

```text
【风格规则】二维线条与色块 / 风格化3D / 写实3D，只选择适合的主媒介。
【形象锁定】头身比例、脸部特征、发型轮廓、服装/装备、色板。
【初始姿态】重心、朝向、武器/法器的位置、对手与地标。
【动作节拍】起势 -> 运动路径 -> 接触/释放 -> 受力/环境反馈 -> 收势。
【特效系统】来源、形状、轨迹、体积、交互光、消散；角色轮廓何时可见。
【摄影机和声音】哪个动作触发机位/焦点变化，哪一声与接触同步。
【结束状态】角色、装备、敌人和场景发生了什么持久变化。
```

若一个指定时长无法让关键步骤被看清，缩短剧情范围或拆为可拼接片段，不用额外术语掩盖时间不足。

## G. 现有提示词诊断与优化

诊断按优先级检查：

1. 用户明确要求是否保留；角色身份是否与参考绑定正确。
2. 主媒介与风格词是否一致；服装与世界观是否协调。
3. 人物、道具和摄影机的空间关系能否同时成立。
4. 动作、对白和表演是否装得进时长；每个镜头有可见终态。
5. 复杂能力是否有来源、路径、受力和结束状态。
6. 是否有不必要的技术词、重复禁项或互相矛盾的指令。

用户要求“优化”时，先保留其剧情和身份；说明少量关键改动，交付优化后的可复制版本。用户只要求“分析”时，重点说架构、有效机制、风险和可复用规律，不擅自改写成稿。

## 故障与修法

| 失败现象 | 常见原因 | 提示词修法 |
|---|---|---|
| 角色换脸 | 身份锚点过少或混用不同参考脸 | 明确脸部参考用途，跨版本重复少量关键锚点 |
| 古装变现代、动漫变真人 | 媒介/时代混写 | 选一个主媒介，材料与光线跟随它 |
| 两人交换位置 | 只写屏幕左右，缺少地标和机位 | 以门、桌、柱等锚定实际位置；换机位重述当前画面 |
| 手、剑、伞跳位 | 持用关系未写，或转身时忽略手臂 | 标出初态、接触路径、终态；不要按画面左推断左手 |
| 多人抢台词 | 没有声音归属与听者动作 | 分配时间、嘴型、视线和画外音规则 |
| 技能只剩光 | 特效遮挡角色或无攻击路径 | 保留轮廓、武器与受力点；说明何时重新成形 |
| 动作瞬移 | 单镜动作过密，缺少中间状态 | 缩短动作链，给移动和接触留时，必要时拆镜 |
| 真人像塑料 | “电影级”取代具体材质与光源 | 写皮肤、发丝、衣料、真实反射和有来源的灯光 |
| 动漫三视图不是同一个人 | 各视图独立重设计 | 同一比例、发根、脸形、服装结构与色板 |

质量检查是对提示词逻辑的检查，不是生成成功保证。模型生成后若有实际失败，应根据失败镜头窄幅修订，避免把所有风险叠成一张越来越长的通用负面清单。
