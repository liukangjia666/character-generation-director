# 风格转译：把审美词写成画面规则

风格名称不能单独承担画面设计。将每个风格拆成可以被看见、听见和检查的规则，再放入提示词。每次只选一个主媒介和一套主风格语法，避免把真人摄影、二维手绘和写实3D的核心规则混写。

## 风格转译表

```text
风格标签
→ 画面材质
→ 光线与色彩
→ 动作节奏
→ 镜头习惯
→ 特效形态
→ 声音质感
→ 禁止的错误观感
```

## 真人电影

把“电影感”拆成真实光源、皮肤与布料材质、摄影机重量、景深范围、演员停顿、环境声和合理的曝光变化。不要用过度磨皮、无来源轮廓光、漂浮雾气或随机慢动作替代真实感。

## 生活化Vlog / POV

把手机视点当成一个人的身体：开门、被拉近、突然停步或对方靠近时，画面会有轻微滞后、手持呼吸、自动对焦和曝光修正。事件要像一次生活中的小发现，动作少而有动机，环境底噪和距离变化比华丽镜头重要。

## 东方水墨武侠

水墨不是黑白滤镜。将墨色浓淡对应力量，飞白对应速度，留白对应空间，断笔对应冲击，晕染对应水火或气流的扩散。人物、武器和环境必须仍有清楚轮廓。火焰可以像笔锋，水刃可以像冷墨线，但每种形态都要由动作路径产生。

## 手绘爆发动画

先建立真实动作，再用爆帧、黑白剪影、速度线、局部形变或色块压缩强调关键事件。前面的普通动作保持可读，主要视觉重音留给局势转折或终结。效果结束后恢复原画面并保留受力结果。

## 写实3D / CG电影

UE5、Lumen、Nanite、PBR等技术词只作为渲染方向，必须连接到可见结果：全局光照如何照亮衣料和地面，Nanite细节出现在哪里，PBR如何区分金属、皮肤、布料和石材，体积雾如何承接光线。技术词不能代替角色设计、动画规律和镜头任务。

## 风格检查

- 是否能从材质、光线、动作、镜头或声音中看出风格？
- 风格效果是否支持角色和事件，而不是覆盖脸、武器或接触点？
- 同一个风格是否在全片保持同一套颜色、线条、光照和运动规则？
- 夸张效果是否有触发、变化和消散过程？
- 是否混入了另一个媒介的核心规则？
