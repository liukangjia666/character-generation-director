# 动作指导、武器力学与视觉重音

打斗先解决动作和空间，再设计镜头和特效。动作不能只是招式名的堆叠，每个动作都要有目的、路径、应对、结果和收招。

## 动作因果链

```text
起手状态
→ 战术意图
→ 发力方式
→ 攻击路径
→ 对手反应
→ 接触或落空
→ 受力与环境反馈
→ 武器回收与重心恢复
→ 下一状态
```

每段至少有一个清楚的目的：抢距离、封路线、逼退、制造空档、拆武器、脱离或改变高度。拒绝无目的连续旋转和双方轮流等待。

## 武器动作边界

- 枪矛：刺、戳、点、挑、拨、架、压、扫杆。刺出后要看枪杆回收、偏转和换脚。
- 刀：劈、砍、斩、削、撩、格、拖切。大刀需要肩腰带动和挥空后的恢复。
- 剑：刺、削、点、撩、格、压剑。重点是直线剑尖、刃线和手腕控制。
- 棍：扫、砸、戳、挑、架、拨。棍两端和杆身惯性要连续。
- 锤：砸、抡、撞、压。重击后必须有减速、回收和重心恢复。
- 匕首：刺、割、挑、贴身控制。距离必须足够近，手腕动作小而快。
- 软兵器：甩、抽、缠、套、拉。必须显示惯性、延迟、缠绕和回收。
- 拳脚肘膝：写清支撑脚、髋部、肩部、接触部位、落地和恢复。

## 视觉重音

先选真正改变局势的一下，再决定是否使用冲击帧。提示词应写清：

```text
触发事件：
接触点：
必须保留的人物、武器和身体轮廓：
背景如何简化：
线条或色块的方向：
效果持续和结束方式：
恢复后攻击者与受击者的状态：
```

冲击帧可以是黑白剪影、短促闪白、反相、闪黑或手绘色块，但不能遮住是否命中。先让观众看懂接触，再让画面变化，随后恢复正常画面并展示退步、偏转、失衡、收拳、回架或武器破裂。

## 技能和特效

每种技能写来源、触发、形状、轨迹、速度变化、作用对象、环境反馈、角色可见性和消散状态。特效不能独立漂浮。火焰可以沿刀锋形成飞白，水刃可以从地面积水聚集，墨焰可以像笔触拉长；这些描述必须绑定身体发力和武器路径。

## 纯技能展示与剧情打斗

纯技能展示可以夸张地突破常规地形，但仍要用地面蹬踏、墙面接触、翼面反推、火浪支点或能量落点证明运动。剧情打斗优先维护对手反应、距离和战局变化。两种任务都必须保持角色的持物方式、身体重心和结束状态。

## 动作审查

- 武器动作是否符合形制和距离？
- 攻击是否有前因，防守是否改变了下一步？
- 命中后是否看到身体和环境的结果？
- 攻击者是否完成收招、回架、落地或重心恢复？
- 是否出现孤立招式、无支撑变向、突然换手或瞬移？
- 视觉重音是否只放在关键事件上？
