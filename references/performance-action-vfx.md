# 角色表演、对白、武打与技能释放

用于视频或连续图中的角色行为，不把这里的动态规则强加到单张肖像。先锁角色身份与当前外观版本，再写镜头内状态。复杂镜头按 `起始状态 -> 可见动作路径 -> 结束状态` 写；后一镜继承位置、朝向、道具、服装损伤和情绪。

## 对白与微表演

一段对白至少明确：谁说、对谁说、画内/画外、语气变化、嘴型归属、其余人的倾听反应、视线与停顿。只有用户有音频参考且工具可访问时才推断具体音色；否则只保留句柄或用户明确描述的声线。

将抽象情绪拆成可观察的节拍：

```text
听到信息 -> 目光停住 -> 呼吸或肩部变化 -> 选择看向对方/避开 -> 开口或沉默 -> 等待反应
```

示例：

```text
0.0-0.8秒：A听完B的话，视线停在B脸上，手指停止翻动书页。
0.8-2.4秒：A缓缓抬眼，用正常语速说自己的台词；B闭嘴倾听。
2.4-3.5秒：A说完仍看向B，B吸气欲言又止；没有新台词。
```

不要让两个角色在没有要求时同步张嘴；画外回答不能配给画内人物。主观镜头明确哪些身体部位可见，避免模型自动加入主观人物的脸、手或反打。对白长度要能装进给定秒数，关键反应留时间；宁可减少台词或镜头任务，不把所有表演挤成持续说话。

## 角色动作签名

为角色建立稳定的动作语法，例如：

- 冷静剑客：先稳住脚下重心，再用短距离剑路反制；动作后剑尖迅速回到可防守位置。
- 近战重拳角色：由髋部带肩，重拳后出现身体惯性与恢复姿态。
- 谨慎宫廷人物：转头慢于眼神，步距小，袖口和手指表达克制。
- 机甲角色：动力源、关节驱动、甲片惯性与能量色保持一致。

动作签名是人物区别，不是所有镜头都重复同一招。

## 武打编排

先说明双方相对固定地标、起始距离、面对方向、武器由谁持有、摄影机在哪一侧。打斗至少有攻击意图、应对方式和状态变化。逐个动作写：

1. 起势与重量：哪只脚承重，躯干如何发力，武器从哪里出发。
2. 攻击路径：向谁的哪个部位、从哪侧到哪侧；镜头是否能看清接触点。
3. 防御与反制：格挡、闪避、借力或受击的实际身体路线。
4. 命中反馈：皮肉/盔甲形变、衣发惯性、身体位移、地面和周围物体反应。
5. 收势与下招：武器和手脚落在什么位置，是否仍有攻击空间。

敌人不能只站着承受连招。交替安排主动攻击、挡拆、位移与失败，保持角色能力差异。镜头越近，动作复杂度越应降低；高速阶段需间歇回到可读的身体轮廓。打击停顿、冲击帧、闪帧、速度变化和镜头震动并非同义词，用户禁止某项时不用其他术语偷偷加回。写“冲击帧”需说明接触点及下一瞬的受力结果，不要求模型精确到某一帧。

## 技能、法术、异能

先设计角色技能系统，再写一次释放：

```text
来源：身体哪处、武器、法器或环境中的什么。
触发：手势、蓄力、呼吸、姿态或接触。
形状：体积、边缘、颜色、内部结构、明暗层级。
轨迹：从哪里到哪里，速度如何变化，是否穿过/绕过物体。
代价或限制：若故事设定有，体现在身体或环境中。
作用：命中点、推动/切割/束缚/照亮/蒸发等具体结果。
反馈：衣发、雨雾、水面、墙体、地面、敌人如何受影响。
消散：能量如何减弱，角色最终姿态和场景状态是什么。
```

角色特效色与敌方色、环境色保持区分；强光不要长期盖住脸、手和动作方向。神圣、古老、压迫等抽象性质用尺度、光源、声场和环境反应表达。巨大技能必须有建筑、人物或地形尺度参照。技能生发点和实际命中点应处于摄影机能理解的同一运动逻辑中。

## 变身与多形态

每一阶段列：仍可辨认的身份锚点、新出现部件、原有部件去向、身体姿态、装备位置、下一形态的起点。机械着甲按部件飞来、对应位置对齐、固定、闭合、核心启动的可见顺序；法术变身按来源、覆盖、结构变化和完成姿态。角色不必站桩等待，但运动路径与部件装配不得互相矛盾。

“光流化”“残影”“空间换位”需要指定哪些时刻能看见脸、躯干、武器或羽翼，以及攻击线路和重新凝聚的位置。纯随机光线无法传达角色动作。

## 摄影机与声音

术语写成执行指令：`从何处开始 -> 跟随哪个动作 -> 到何处停住 -> 观众看清什么`。贴身跟拍保留人物与地标的关系；过肩镜头要保留表演或接触部位；移焦注明前后焦点；甩镜结束后需要稳定落点；环绕注明起止侧，避免不经意交换屏幕关系。

声音按发生原因组织：呼吸、衣料、脚步、兵器、能量、接触、环境回响。台词和拟音的时间与动作同步。背景音乐、字幕、HUD等由用户要求决定，不设默认有或无。

## 生成前专查

- 说话人、嘴型、声音、表情是否属于同一角色。
- 手里道具、武器和身体接触在动作前后是否连续。
- 打击点与摄影机位置是否同时允许观众看清攻击和受力。
- 技能的来源、轨迹、作用对象与环境反馈是否对应。
- 变身后的结构是否继承前态，而非新生成一个无关角色。
