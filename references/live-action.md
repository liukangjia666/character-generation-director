# 真人角色：竖屏短剧与电影

只有真人摄影、真人短剧、电影剧照或真人视频角色任务读取。先判断交付是“独立角色资产”还是“带剧情的表演片段”；前者让人物可复用，后者再加入镜头内情绪和动作。

## 两种制作语法

| 维度 | 红果式移动端短剧 | 电影或高规格剧集 |
|---|---|---|
| 首屏识别 | 快速看清谁、身份或关系变化；面部与服装色块清楚 | 可以通过空间、行为和局部线索逐步揭示 |
| 构图 | 常见9:16；脸、手与关键道具在中心可读区域，适当利用纵深 | 按场景选择画幅；可保留更多环境关系和留白 |
| 表演 | 情绪转折更快，但微表情仍要有前因后果；台词和反应分明 | 允许更长的视线、呼吸、沉默与未说出口的动作 |
| 服装与妆发 | 一眼可识别阵营或处境，细节在手机画面仍有效 | 材质、磨损、剪裁与时代逻辑经得住近景和全景 |
| 摄影 | 以动作和关系可读为先，避免为炫技频繁切镜 | 景别、机位、光源和运动由人物视点与戏剧任务决定 |
| 声音 | 台词清楚，画内外归属清楚，反应留出短暂停顿 | 环境声、呼吸、空间混响与留白共同表演 |

两者不是“低级”和“高级”的关系。短剧需要压缩信息，电影允许更丰富的观察；根据用户给的节奏与审美调整，不能机械要求所有短剧夸张表情或所有电影缓慢。

## 角色可见身份

写真人角色时优先解决：

1. 脸部：脸型与骨相、眉眼结构、皮肤年龄感、独特痣/疤或其他辨识点。不要把“顶级颜值”当身份锚点。
2. 头发：正面发际、鬓角、侧面和后脑形状，发饰的安装位置；长发在动作中是否会遮脸。
3. 身体：身高关系、肩背与重心、步态和手势习惯；不要只写精确厘米而不说明与他人同框的尺度。
4. 服装：内层、外层、领口、袖型、腰部、鞋履；哪些部位必须能支撑坐下、抬臂、跑动、打斗。
5. 表面：真实毛孔与细发、化妆贴合、布料织纹、金属使用痕迹、湿润/汗水来源。真实感来自一致材质和光线，不来自堆技术引擎名。
6. 角色功能：主角、对手、盟友、侍从等可用行动、视线与服装层级表达；不用符号化套路替代人物个性。

## 古装真人

- 先确定时代参照或架空规则。唐、宋、明等不能混成“古风”而同时声称严格历史；架空服制可以创新，但同一世界的等级、面料和佩饰规则要一致。
- 角色身份体现在衣襟、冠饰、发式、用料、配色和穿戴层级，不用满身金饰代替权力。
- 行走和打斗要顾及袖口、下摆、披风、发簪与兵器的物理关系。穿着宽大礼服的角色不能无交代完成紧身武服式翻滚。
- 亲密、挽臂、递物、持伞等接触动作写清哪一侧身体靠近、哪个手臂被占用、镜头是否看得见接触点。不要把屏幕左/右误当作角色左/右手。
- 固定场景里常用门框、柱、帘、灯、桌和石阶给人物定位。摄影机换侧时重新说明当前画面关系。

## 现代真人

- 职业、收入、阶层、性格通过服装合身程度、磨损、配件、妆发和工作姿态体现；不依赖标签。
- 同一场景保持外套、包、眼镜、手机、戒指等状态；摘下或交给别人要有可见动作。
- 不为“电影感”自动加入霓虹、湿地或烟雾。光源按办公室、家中、街道、车内等真实环境决定。

## 常见人物段落

**情感短剧：**首先建立谁看见了什么，然后写反应的时间差。近景可读到眼神和嘴角，下一镜保留被看见的人或道具。误会要有真实可见的误读对象，不能靠旁白解释。

**权谋或对峙：**角色的位置与礼制关系先成立，视线、距离、座次、谁先起身或让路构成权力变化。反打要保持视线方向，不能因为镜头转向而把双方位置交换。

**武侠或动作：**衣袍、佩剑、鞘与手的关系是角色设计的一部分。动作用身体重心、起势、攻击线和命中后的收势区分人物，不给所有角色同一种“快如闪电”的招式。

**仙侠或超自然：**先保住真人脸、衣服和动作；特效从身体、法器或环境明确生发，照亮布料、皮肤与空间；能量强度随剧情升级，不能从第一帧一直覆盖面部。

## 交付时的媒介校准

独立角色图可要求中性或典型动作、正面/侧面/背面及细节页；不要用强烈戏剧光和复杂背景遮住服饰结构。剧情剧照或视频可有动机性光源与环境互动，但必须保留人物识别点。纵向短剧特别检查头饰、剑、手部接触和第二人物是否被边缘裁掉。
